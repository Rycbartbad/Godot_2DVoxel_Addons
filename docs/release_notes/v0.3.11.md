# v0.3.11 —— 引擎侧根治"碎片渲染位置偏差"（节点层不变量自动维护）

## 一句话

`_body_nodes` 与 `world.bodies` 的**下标一一对应**不再需要消费者自己维护：
`PWorld` 新增 `bodies_rev`，`PixelWorld` 每帧按版本号自动 `realign_body_nodes()`。
任何**绕过节点层**增删刚体的路径（灰尘策略的 `remove_body`、直接 `fracture_pixels`、
门面 `spawn_*`、调试脚本的 `add_body`）都不会再让渲染错位或中断。

## 根因：症状不是报错，而是"贴图停在旧位姿"

游戏层的每帧渲染同步循环是**按下标**取节点的：

```gdscript
for i in world.bodies.size():
    var body = world.bodies[i]
    var node = _body_nodes[i]      # ← 这里
```

而那条硬不变量只在**走节点层**的路径上成立。绕过它的路径有：

| 路径 | 行为 |
|---|---|
| **灰尘策略** `debris_max_mass` / `debris_min_speed` | 引擎内部 `remove_body()`，直接改 `world.bodies` |
| 直接调 `PWorld.fracture_pixels()` | 只进 `world.bodies`，不补位 |
| 门面 `spawn_*` / 调试脚本 `world.add_body()` | 同上 |
| 游戏正常路径 ✓ | `commit()` → `fracture_pixels` → `sync_world_bodies()` → 同帧已对齐 |

两种破坏方式，症状**都不是报错**：

- 数组**变短**（加了刚体没补位）→ `_body_nodes[i]` 越界；这个循环没有 `try` →
  **整段同步就此中断** → 下标在它之后的刚体（通常正是刚分出来的碎片）这一帧不再被
  `sync()`，贴图停在旧位姿 —— 实测 30 帧里 **8 次** `Invalid access of index '5'`，
  偏差从 0 持续涨到 **4.1 px**，新碎片甚至完全不出现；
- 数组**变长**（删了刚体没删位）→ 不报错，但下标整体错位 →
  `has_own_sprite()` 去问**别人的节点** → 同样漏同步。

## 改动（纯 GDScript，这一版**没有**动 DLL）

```gdscript
# PWorld：刚体增删的版本号
var bodies_rev := 0            # add_body / remove_body 各 +1

# PixelWorld._physics_process：按版本号对齐
if _bodies_rev != world.bodies_rev:
    _bodies_rev = world.bodies_rev
    realign_body_nodes()
```

- 平时只是一次**整数比较**，不是每帧 O(n)；
- ⚠️ 对齐必须放在**节点自己的 `_physics_process`** 里（不能只在 `sync_world_bodies` 里）——
  因为"按下标取节点"的消费方是**游戏层**，而它的 `process_physics_priority` 比世界节点大 1
  （跑在后面），所以世界节点先对齐、游戏层再取，顺序天然正确。

## 闸门

`tests/validation_body_nodes_invariant.gd`（**8 项**）：

| 断言 | 结果 |
|---|---|
| 直接 `add_body` 后不变量暂时破坏（预期）| nodes 1 / bodies 2 ✓ |
| **走一帧后自动对齐** | nodes 2 / bodies 2 ✓ |
| 直接 `remove_body` 后走一帧自动对齐 | nodes 1 / bodies 1 ✓ |
| `add_body` / `remove_body` 真的 bump `bodies_rev` | 3 → 4 → 5 ✓ |
| **没有增删时不动数组**（省掉每帧 O(n)）| ✓ |

## 验收

- **8 条逐位基准逐位不变**；
- 全部测试非零退出 = 0（含新闸门 8 项）；
- 本版**只改 GDScript**（`pworld.gd` / `pixel_world.gd`）—— **不需要**重编或重启加载 DLL；
  但如果你还在 v0.3.9 或更早，v0.3.10 的 `fastphys.dll`（op 2 原生矩形分解）需要重启编辑器才生效。

## 游戏侧那两行可以留着

之前在对症处加的 `realign_body_nodes()` + `i < size` 兜底**无害**，是双保险；
现在即使忘了也不会再出问题。
