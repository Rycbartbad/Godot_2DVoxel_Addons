# v0.3.3

从 v0.3.2 起共 14 个提交。这一版的主线是**接触点接口**：把"一次碰撞到底发生在哪些点、
每个点各撞得多狠"完整地递出来，并让多个损伤入口**共同分配**一次碰撞的预算。

## 背景：旧接口把整个面的冲量附在了一个点上

旧接口（`rb_contact_get`）取 `manifolds().first()` 的 `points.first()` 作**位置**，
却用 `pair.total_impulse()` 作**冲量** —— 一个点背着整个面的冲量。
宽面撞击照着这个点打洞，就会集中成一次尖刺攻击。

⚠️ 而且它在项目里**静默返回全 0**（实测），所以这一版把它整个删掉了（Rust + C++ 两侧一起）。

## 现在能拿到什么

| 接口 | 给出 |
|---|---|
| `PWorld.contact_pair_count()` | 本步的接触对数量 |
| `PWorld.contact_points(idx)` | **全部**接触点：`{normal, position, dist, impulse, fid1, fid2}` |
| `PWorld.contact_info(idx)` | `{points, total_impulse, id_a, id_b}` |
| `Contact.points / total_impulse` | 事件侧同样有（需 `contact_events_enabled`）|
| `Contact.contact_width` | **真实接触宽度**（沿切向数"两边都实心"的体素，是应力判据的分母）|

实测（32 宽方块平放落在静态地面）：

    点数 2；位置 (50,100) 与 (82,100)     <- 接触段的两端
    各点冲量 1280.0001 / 1280.0001
    整对总冲量 2560.0002，各点之和 / 总冲量 = 1.0000

## 共享预算：多个入口共同分配一次碰撞的预算

`Destruction.contact_entries(points, total_impulse, base_radius)` 把一次碰撞变成多个损伤入口，
**面积按份额分配**：`radius_i = base_radius * sqrt(share_i)`，`share_i = |impulse_i| / total_impulse`。

⚠️ 若每个点都用同一半径，总损伤面积就是单点的 N 倍 —— 那正是"重复领取整份伤害"。
实测：两点各 share 0.5 → radius 5.6569（= 8/sqrt(2)），Σ面积 201.0619 = 单点面积，**比值 1.0000**。

## ⚠️ 面积：做了，又按决定删掉（原因留档）

第一版给的是"带宽面积"（宽度 x 平均深度），随后发现它**在角接触上是结构性错的**：
窄相只给 1 个点 → 宽度就是 0 → 面积算成 0，而真实重叠是一个非零的小三角形 ——
**静默的错值最坏**。真正的"相互进入的面积"是两个 OBB 相交多边形的面积，要它必须先知道
**是哪两个矩形在相交**，而实测证明 feature id **不带**这个信息
（`tests/diag_fid_rect.gd`：同一个方块砸在同一个两矩形刚体的左半与右半，fid **完全相同**）。

结论：**各点冲量已经够用**，面积接口删除；要精确面积时的路径写在 `contact_info` 的墓碑注释里。

## ⚠️ feature id 的定位（说大过一次，已更正）

feature id 是**面/顶点级**特征（warm start 靠它），**不含矩形索引** ——
跨帧去重**必须和位置（或矩形索引）组合**，不能只靠它：方块从矩形 A 滑到矩形 B 时 fid 可能不变。

## 端到端闸门

`tests/validation_impact_damage.gd` 把整条链真正跑一遍：接触事件 → 应力门槛 →
`contact_entries` → `world.fracture`。实测（32 宽锤子以 900 px/s 砸静态墙）：

    墙像素 9600 -> 9504（被打掉 96）
    施加次数 = 2，半径 = [5.6569, 5.6569]   <- 预算共享成立（不是各用 base=8）

## 其它修复

- **两处"重构改了语义、测试没跟上"的陈旧期望**（`validation_query` 的 AABB 断言、
  `validation_alignment` 在 headless 下的挂死）—— 它们**红/挂着发布了两版**
  （v0.3.1 与 v0.3.2 都带着）。挂死的根因是 GDScript 运行时错误会**中断 `_initialize`**、
  永远走不到 `quit()`。
- 删除**静默返回全 0** 的 op 12（连 Rust 函数、函数指针、`RP_GET` 绑定、协议注释一起）。
- 删除死变量 `ccd_substep_hold`（声明了、注释引用了，代码从没读过）。
- demo 新增**撞击伤害规则**（`impact_damage`，默认关）—— 这是**游戏规则**：
  引擎只提供数据（撞得多猛、面多宽、进去多深）。
